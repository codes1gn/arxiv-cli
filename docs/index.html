Features

The arXiv interface your AI agent deserves

arxiv-cli speaks JSON natively, caches aggressively, and pairs with a SKILL.md so your agent knows exactly how to use it.

🔍

Semantic Search

Search by title, abstract, author, or category. Supports arXiv query syntax plus natural-language queries that get rewritten automatically.

📥

Structured Fetch

Download any paper's metadata, abstract, sections, and equations as structured JSON. Agents can read it directly without PDF parsing.

💾

Local Cache

Every fetched paper is cached in ~/.arxiv/papers/. Subsequent reads are instant and work offline. TTL configurable.

📝

Citation Formatting

Output BibTeX, Markdown, or inline citation strings. Your agent uses arxiv cite 2205.14135 and pastes directly into README or LaTeX.

📋

Reading List

Manage a personal reading list with tags. arxiv list --tag cuda returns all bookmarked GPU papers as JSON in one shot.

🤖

AI-Native Skill

SKILL.md instructs Copilot and Cursor exactly how to call arxiv and embed paper summaries into code comments automatically.

Install arxiv-cli

Python 3.8+. Uses the official arXiv API, no API key required.

$ git clone https://github.com/codes1gn/arxiv-cli
$ cd arxiv-cli && pip install -e .
$ arxiv search "attention is all you need" --limit 5
