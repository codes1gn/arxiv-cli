Works on macOS · Linux · Windows — Python 3.8+

🔧 Commands

🔍

arxiv search

Search by query, author, category. Human or JSON output.

📅

arxiv recent

Recent papers in a field by date. Perfect for daily monitoring.

📄

arxiv get

Full details of a paper by arXiv ID. Shows full abstract.

⬇️

arxiv download

Download PDF to a local directory with one command.

Search examples

$ arxiv search "BERT language model" --limit 10 --json
$ arxiv search "RL policy gradient" --author "Schulman"
$ arxiv search "diffusion models" --category cs.CV --limit 20 --json

Browse recent papers

$ arxiv recent cs.LG --days 7 --json
$ arxiv recent cs.CL --days 3 --limit 10

Lookup + download

$ arxiv get 1706.03762 --json
$ arxiv download 1706.03762 --out ./papers/

🤖 For AI Agents

arxiv-cli is designed agent-first. Use --json for structured output that agents can parse directly.

JSON output schema

{
  "id": "1706.03762",
  "title": "Attention Is All You Need",

  "published": "2017-06-12",

  "pdf_url": "https://arxiv.org/pdf/1706.03762",
  "abs_url": "https://arxiv.org/abs/1706.03762"
